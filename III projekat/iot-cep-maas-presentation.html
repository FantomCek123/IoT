@app.post("/predict")
def predict_anomaly(data: SensorData):
    prediction = model.predict([[data.temperature]])[0]
    probability = model.predict_proba([[data.temperature]])[0][prediction]

    return {
      "status": "CRITICAL_ANOMALY" if prediction == 1 else "NORMAL",
      "probability": probability
    }
05 CEP Engine

eKuiper Stream Processing

Deklarativna SQL pravila nad MQTT tokovima: temperatura > 50°C → alarm

CREATE STREAM iot_stream () WITH (
  DATASOURCE="iot_sensor_data",
  FORMAT="json", TYPE="mqtt"
)

SELECT temperature,
  "ALARM: Visoka temperatura!" as poruka
FROM iot_stream
WHERE temperature > 50
MQTT Topic: sensors/ekuiper_alarms Real-time Edge Processing
